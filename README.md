# JaySuen Repo

JaySuen 的 iOS 越狱插件源，当前提供 Evo Center、IslandBlur 与 ArtMotion。

- 软件源地址：`https://eleveny123.github.io/`
- 备用地址：`https://eleveny123.github.io/EvoCenter/`
- Rootless 架构：`iphoneos-arm64`
- RootHide 架构：`iphoneos-arm64e`
- Evo Center 支持说明：iOS 16.0–17.4，已确认支持 iOS 16.7；其他版本自行测试。

在 Sileo、Zebra 或其他兼容 APT 的越狱包管理器中添加上述地址即可。

## ArtMotion Beta1.0

- [ArtMotion](https://eleveny123.github.io/ArtMotion/)：arm64e 设备。
- [ArtMotion（Legacy）](https://eleveny123.github.io/ArtMotion/legacy.html)：arm64 设备。
- 两个版本均提供 Rootless / RootHide 安装包，每包同时支持 iOS / iPadOS 16、17。
- 开发者：ChatGPT6.1、JaySuen。
